# v0.4.1 免费实例后台

本变更仅涉及 Python 后台、测试与说明。使用现有标准库启动命令，不增加依赖、数据库、磁盘或收费资源。现有服务地址和环境中的 Token 不变；本地验证不连接正式服务。

## 数据与命令生命周期

| 对象 | 行为与上限 |
| --- | --- |
| 截图 | 单槽内存，最大 24 MiB；新上传覆盖并清除旧图；未读 120 秒失效。 |
| 截图读取 | 鉴权后 `/api/latest` 原子取走一次，发送结束或失败均清零缓冲；第二次 404。`/api/latest.json` 仅查看元数据，不消耗图片。所有响应 `Cache-Control: no-store`。 |
| 启动会话 | 每个进程生成随机 epoch；不读取磁盘队列、截图、历史命令或旧钩子。 |
| 命令 | ID 为 `epoch~随机值`；轮询时移出队列，不因超时、断线或缺少回报重新入队。120 秒仍 pending/dispatched 则 failed + invalidated，禁止重放；这不表示动作确定未执行。 |
| 历史 | 最多 256 条、保留 600 秒，仅含 ID、epoch、设备、动作、状态和时间。业务参数只在待发送队列暂存。队列满返回 429。 |
| 结果 | 执行结果仅供业务查询，首次终态查询或收到后 60 秒清除内容，不保留完整 report。 |
| 旧命令 | 当前进程不认识的 ID 返回 failed + invalidated；旧会话、重复、提前或设备不匹配回报 409。禁止带旧命令 ID 创建新命令；可选 expected_epoch 不匹配则 409。 |
| 状态 | 设备/健康业务快照各最多 16 台，仅内存保留最近 300 秒；供既有接口读取，不进入诊断或日志。 |
| 诊断 | 鉴权 `/api/diagnostics` 仅输出 epoch、启动时间、计数、队列/记录/图片字节数和解除限制关闭标志。请求日志仅记录 HTTP 错误码，不记录 URL、查询凭据、正文、图片或结果。 |

后台每秒清理到期数据，访问时再次检查期限；系统调度暂停时无法保证物理清零恰好发生在到期毫秒，但恢复后禁止读出过期数据。清零仅针对应用持有的图片缓冲，不承诺操作系统、TLS 或调用方副本的物理抹除。

远程解除限制默认关闭：后台拒绝 unlock_app、temporary_unlock_app、remove_locked_app，以及 Curbox `enable=false`（含序列嵌套），手机原有默认关闭开关及命令 ID 持久去重保持不变。本版后台不提供解除限制的远程开关。

## 候选 APK 与 MCP 兼容性

已核对冻结的 v0.4.1 候选源码：命令 ID 按不透明字符串保存并在写动作前登记；附加 epoch 字段会被忽略。以下请求路径、鉴权头、必要字段和成功码均保持兼容：

- `GET /api/poll?device_id=...` 返回 `command: null` 或命令对象。
- `POST /api/device/report` 继续使用 device_id、command_id、ok、result；手机只要求成功码，不依赖旧回报正文。
- `POST /api/device/state`、设备状态别名和健康接口保持原有字段。
- `POST /api/screenshot` 接收原 JPEG/PNG 字节；手机仍以 2xx 认定后台接收。
- 既有 MCP 的 postCommand、waitCommand、commandStatus、latestInfo、fetchLatestImage 原函数已通过真实本地 HTTP 验证。failed + invalidated 是终态，不再无限等待旧会话命令。

这是必要接口兼容，并非保留旧的重复读图/长期结果保留/允许解除行为。截图一次读取后消失、结果首次取走后内容为空是刻意收紧。无需修改、重新签名或重建候选 APK。

限制：候选 APK 不校验 epoch，因此后台无法撤回已送达手机、正在执行的旧动作；迟到回报被拒绝不等于动作未发生。服务端和既有 MCP 均不自动重试写 POST；没有 ID 的独立重复 POST 无法辨别为传输重复还是用户新指令。任何结果不明的写操作先查询实际状态，再由用户明确下发新命令，不承诺端到端 exactly-once。

## 自动验证

运行 `python -m unittest discover -s server -p test_volatile_server.py -v`，需要 Node 可执行文件以运行现有 MCP 原函数的本地 HTTP 测试。测试仅绑定回环地址，生成临时凭证与合成 PNG，不接触手机或正式后台。

覆盖并发单读、TTL 清零、上传替换、发送中断、错误鉴权不消耗图片、命令超时不重放、旧 epoch/重复回报、元数据脱敏、远程解除序列拒绝、请求大小限制、无文件/钩子，以及真实子进程终止重启后队列和图片消失。

## 受控部署方案（尚未执行）

1. 用户批准后才准备后台专用提交；只包含本说明、后台实现、配置示例和两份测试，不混入冻结的 Android 变更。重新只读核对 Render 跟踪分支、自动部署与 Blueprint 关联。当前生产跟踪分支推送会触发部署，因此不得直接推送该分支。
2. 先冻结新写命令，等待已派发动作确认结束；结果不明的动作不得再次下发。批准窗口内由用户停下手机桥，避免跨版本在途命令。没有 epoch 校验的客户端无法获得远程强制撤回保证。
3. 经用户授权后关闭自动部署，推送隔离的后台候选分支，指定审核后的提交手动部署到现有免费服务。保留服务、地址、Token、环境配置和标准库启动命令；不设置持久盘、数据库、付费实例或 Deploy Hook。若不能确定自动部署隔离，停止。
4. 旧版可能留下磁盘截图；新代码忽略它们，不自动删除。批准后仅核对旧截图目录与文件数量，按明确目录进行一次清除，不复制或备份图片。新实现不再调用旧 LINJIAN_HOOK。
5. 验证新版本健康、epoch、缺失/错误凭据拒绝、旧 ID 作废，以及一张合成图上传—鉴权读取—哈希核对—第二次 404；不重测已通过的手机项目。确认冷启动后的重新连接，不自动补发旧写命令。
6. 回退只能使用已经过同等内存清理验证的版本；不得直接恢复旧的磁盘存图和历史命令重放行为。没有安全回退版本时停止接收写命令并修复，不恢复旧队列。

免费实例休眠/重启后所有易失状态丢失是设计行为。必须单进程、单实例运行；多 worker/多实例各有独立内存，不能依赖负载均衡保持会话。接受首次冷启动延迟，不增加保活流量或付费资源。
